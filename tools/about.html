About this project

Why I built Link Card Studio

When a small business shares its page on Facebook or Messenger, the link card is often the first thing customers see. Too often it shows the wrong photo, a cut-off title or no description at all, because the meta tags were never set. Most preview tools need a live URL and a server to fetch it. This one works on a draft, offline, before anything is published.

Who it is for

  • Bloggers and small business owners on Blogger or WordPress
  • Web developers and freelancers who hand sites over to clients
  • Marketing staff of schools, cooperatives and LGU offices who post links every day

What it does

  • Live previews for Google (desktop and phone), Facebook, X, LinkedIn and chat apps
  • A pixel ruler that measures the title in the same font Google uses
  • 11 checks with a score: lengths, https, image size and 1.91:1 shape, alt text, site name
  • Copy-ready tags as plain HTML, a dynamic Blogger theme snippet, or a WordPress mu-plugin
  • Reads an existing page's source and shows which tags are missing
  • Makes a simple 1200 × 630 title-card image, and saves cards in your browser

Use it or install it

Open index.html in any browser, or host the folder on GitHub Pages or any web host. There is no build step and no server code. The source is on GitHub under the MIT license.

Languages used

{{LANGS}}

JavaScript does the measuring, checks and code generation; HTML is the page; CSS is the design system with light and dark themes. No frameworks, no npm, no tracking.

For clients

Link previews are an easy, visible win to sell: a one-time "share card setup" for an existing site, or part of every new website package. The Blogger and WordPress snippets make the fix take minutes.

Privacy

Everything runs in your browser. Nothing you type or upload leaves it.
